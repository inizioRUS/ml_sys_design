# Обновление открытого музыкального плеера fooyin 0.15.0 под Windows и Linux

Разработчик открытого проекта музыкального плеера [fooyin](https://github.com/fooyin/fooyin) [представил](https://github.com/fooyin/fooyin/releases/tag/v0.12.2) обновление с версией для Windows. Ранее решение было доступно только для Linux, а вариант для macOS находится в разработке. fooyin — это настраиваемый плеер, который предлагает гибкое воспроизведение без пауз, расширенные плейлисты, управление библиотекой, поддержку FooScript, плагины и обширную интеграцию. Исходный код решения написан на С++ и опубликован на GitHub под лицензией GNU General Public License v3.0.

«Это ещё один релиз с исправлениями ошибок, но он также знаменует собой первый официальный релиз fooyin для Windows. Поддержка Windows всё ещё находится в стадии разработки и ещё не прошла такое же масштабное тестирование, как Linux. Она будет получать такой же уровень постоянной поддержки, и отзывы и сообщения об ошибках от пользователей Windows особенно приветствуются. Этот релиз включает вывод WASAPI, встроенный тёмный режим и несколько улучшений интерфейса, специфичных для Windows», — пояснил автор проекта.

Построенный с учётом расширяемости, fooyin поддерживает плагины для виджетов, декодеров, считывателей тегов, DSP и интеграций. Он также включает FooScript для расширенного форматирования отображения, запросов, автоплейлистов и настройки поведения виджетов.

Основные возможности fooyin:

- воспроизведение всех основных форматов, включая FLAC, MP3, MP4, Vorbis, Opus, WavPack, WAV, AIFF, MKA, Musepack и Monkey’s Audio. Встроенная поддержка форматов VGM и трекеров/модулей через дополнительные плагины. Воспроизведение без пауз и с точностью по битам. Воспроизведение непосредственно из архивов. Полная поддержка CUE-таблиц, включая встроенные метки. Поиск интернет-радио и удалённое воспроизведение аудиопотоков. Поддержка ReplayGain. Настраиваемые затухания и кроссфейды для переходов воспроизведения. Цепочки DSP со встроенными и предоставляемыми плагинами. Ползунок прокрутки волновой формы, спектр и другие визуализации. Гибкая настройка аудиовыхода и устройств;
- библиотека, плейлисты и метаданные. Расширенная фильтрация и поиск по данным библиотеки и плейлистов. Стандартные плейлисты, динамические автоплейлисты и очередь воспроизведения. Импорт и экспорт плейлистов в форматах M3U и M3U8. Древовидное представление библиотеки и просмотр каталогов. Встроенный редактор тегов и управление метаданными. Инструменты встраивания, загрузка, просмотр, экспорт и извлечение обложек;
- виджеты, скрипты и настройка. Полностью настраиваемый интерфейс с нуля или с использованием предустановленных макетов. Поиск, редактирование, синхронизация и отображение текстов песен. FooScript для расширенного форматирования, логики отображения, запросов и автоплейлистов. Форматирование текста и скриптов в большинстве виджетов и представлений. Персонализированные сочетания клавиш. Расширяемая система плагинов;
- интеграция: поддержка MPRIS для элементов управления рабочего стола и мультимедийных клавиш. Скробблинг с Last.fm, Libre.fm, ListenBrainz и пользовательскими сервисами. Расширенное отображение статуса Discord.

Список изменений fooyin 0.15.0:

- добавлено настраиваемое расширение треков и отображение обложек в фильтре библиотеки, а также анимированные переходы макета и именованные предустановки виджетов;
- расширена настройка сочетаний клавиш с настраиваемыми целями для сфокусированного виджета и воспроизводимого трека, включая элементы управления рейтингом;
- добавлены настройки для автоматического воспроизведения и кроссфейдинга для каждого трека;
- улучшена обработка звука с параллельным преобразованием, расширены элементы управления воспроизведением из командной строки, возможность поиска по ограниченному количеству HTTP-файлов и опция отключения программного управления громкостью;
- добавлены настраиваемые фоны, стили строк воспроизведения и параметры масштабирования обложек для поддерживаемых виджетов;
- улучшена группировка дерева библиотеки и редактирование предустановок, с поддержкой встроенных редакторов рейтинга и «лайков», пользовательских символов и индикаторов ошибок скриптов;
- расширена настройка фильтра с подгонкой обложек, скриптами группировки столбцов, регулируемыми полями, наложенными подписями и счётчиками треков в скриптах столбцов;
- улучшено редактирование автоплейлистов с предварительным просмотром треков в реальном времени, сопоставлением количества треков и пользовательскими скриптами сортировки;
- добавлен lyrics.ovh в качестве онлайн-источника текстов песен и введены тайм-ауты передачи для всех онлайн-провайдеров;
- улучшена отзывчивость Radio Browser, фильтрация, отображение обложек и настройка макета;
- улучшена обработка библиотеки и метаданных с более быстрым поиском повторяющихся треков, настраиваемыми рейтингами MP3, хранящимися в полях POPM, и дополнительными переменными источника треков для скриптов;
- повышена надёжность воспроизведения благодаря исправлениям ошибок инициализации аудио, смены треков, HTTP-потоков, воспроизведения без пауз, вывода ALSA и границ CUE/глав;
- исправлены многочисленные проблемы интерфейса, связанные с сочетаниями клавиш, выделением, кэшированием обложек, редактированием макета, поисковыми соединениями, свойствами и сбоями редактора тегов;
- устранены проблемы плейлистов, влияющие на перетаскивание, групповое выделение, встроенное редактирование, обновление метаданных и асинхронный импорт;
- исправлены ошибки скриптов, связанные с уровнями каталогов, числовым счётчиком треков, расширением тегов, регистром символов и сбоями $swapprefix;
- улучшена обработка метаданных потоков Discord и всплывающие подсказки для обложек;
- обновлены сборки для Windows, упаковка плагинов, файлы среды выполнения и переводы; сборки для X11 теперь требуют компонентов XCB, используемых Global Shortcuts.
