# Microsoft предлагает баллы программы Rewards пользователям New Outlook

В попытке «пересадить» пользователей с классической версии Outlook на новую Microsoft будет предлагать баллы программы Rewards. Значок программы появится в строке заголовка Outlook, при нажатии он будет открывать доступные задания.

По [данным](https://www.windowslatest.com/2026/11/08/microsoft-is-begging-you-to-ditch-outlook-classic-and-now-its-handing-out-rewards-points-to-try-new-outlook-on-windows-11/) Windows Latest, стартовые задания касаются простого ознакомления с функциями, которые присутствуют в New Outlook. Так, первое задание «Автоответы, пока вас нет» (Out of office, covered) открывает настройки автоматических ответов в Outlook. Задание засчитывается как выполненное, даже если пользователь не активирует саму функцию, а только открывает настройки.

Второе задание, «Входящие без лишнего шума» (An inbox without the noise), открывает страницу с ценами на подписку Microsoft 365 (даже для пользователей, у которых подписка уже есть). Третье задание «Сделайте каждый день чуть проще» (Make every day a little smoother) представляет собой поисковый запрос «повысьте эффективность работы в Outlook» (boost your Outlook efficiency) в поисковой системе Bing. Баллы начисляются за открытие результатов поиска.

За выполнение первых трёх заданий можно получить 30 баллов Rewards. Новые задания будут появляться каждый день. Предполагается, что все они будут связаны с освоением New Outlook.

С точки зрения Microsoft, классическая версия Outlook постепенно уходит в прошлое. Хотя поддержка существующих установок продлится как минимум до 2029 года, этап отказа от старой версии начнется в 2027 году: корпоративных пользователей начнут автоматически переводить на New Outlook (если администраторы не заблокируют этот процесс). При этом у пользователей останется возможность вернуться к классическому Outlook. На следующем этапе — окончательном переходе — возможность возврата к старой версии будет полностью удалена.

Ранее Microsoft [признала](https://support.microsoft.com/en-gb/support/known-issues/classic-outlook-issues-with-service-assisted-search-for-shared-mailboxes), что в классическом Outlook результаты поиска могут не обновляться после перемещения или изменения элементов почтового ящика. Компания предложила временное решение с использованием службы Windows Desktop Search.
