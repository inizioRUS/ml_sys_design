### Готовые промпты под популярные задачи

#### Текст: статья или пост

```
Ты редактор делового издания. Напиши текст на тему [тема] для [аудитория].
Объём: 3000-4000 знаков. Структура: вступление на 2-3 предложения,
3-4 смысловых блока с подзаголовками, вывод.
Тон спокойный, без канцелярита и общих фраз. В каждом блоке один
конкретный пример или цифра. Если цифр у тебя нет, оставь пометку
[нужна цифра], а не придумывай.
В конце дай 5 вариантов заголовка.
```

#### Учёба: разобрать тему и проверить себя

```
Объясни тему [тема] студенту [курс, специальность], который видит её впервые.
1. Суть в трёх предложениях без терминов.
2. Подробное объяснение с терминами, каждый термин поясни.
3. Один пример решения задачи по шагам.
4. Пять типичных ошибок и как их не допустить.
5. Тест из 8 вопросов с вариантами ответов, ответы отдельным списком в конце.
```

Пример: для темы «производная сложной функции» модель разберёт правило на одной функции, а в тесте даст задачи, где ошибку легко сделать при выборе внутренней функции.

#### Код: найти ошибку и исправить

```
Ты опытный разработчик на [язык]. Ниже код и текст ошибки.
1. Объясни причину ошибки простыми словами.
2. Покажи исправленный фрагмент целиком.
3. Проверь, нет ли рядом похожих ошибок или граничных случаев.
4. Напиши 3 теста, которые поймали бы эту ошибку.
Поведение остального кода не меняй, новых зависимостей не добавляй.
[код]
[текст ошибки]
```

3. Пункты, которые противоречат друг другу, с номерами разделов.
4. Формулировки, которые можно понять двояко, и как их уточнить.

В конце одной строкой укажи, какой вариант уместнее и почему.
