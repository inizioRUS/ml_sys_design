# Microsoft создаст единый центр обновлений для приложений в Windows 11

Microsoft [планирует разработать](https://www.windowslatest.com/2026/11/09/for-20-years-windows-apps-like-java-have-nagged-you-with-their-own-update-pop-ups-and-windows-11-now-wants-to-end-it/) для Windows единый центр обновления всех установленных программ. Большинство сторонних сервисов, распространяемых вне Microsoft Store, сейчас используют собственные установщики.

Microsoft планирует сделать процесс обновления приложений менее разрозненным. Ещё в декабре 2025 года появился раздел «Обновления приложений» (App updates) в меню «Параметры» > «Приложения», а недавно он снова появился в предварительной сборке Windows 11 26H2 — это намекает на полноценный запуск функции.

Microsoft рассчитывает, что разработчики зарегистрируют свои программы в системе единых обновлений Windows 11, и это позволит управлять ими через специальный раздел в «Параметрах».

В 2025 году компания уже представила концепцию под названием «Платформа оркестрации обновлений Windows» (Windows Update Orchestration Platform, UOP). Она позволяет разработчикам регистрировать обновления своих приложений в Windows 11 в качестве «поставщиков» (providers). Благодаря этому Windows сможет периодически проверять наличие обновлений для таких программ и координировать их установку.

Microsoft не стремится заставить разработчиков отказываться от уже существующих механизмов обновления: сторонним приложениям не нужно менять свои серверы обновлений или логику установки. Она лишь предоставляет уровень оркестрации. «Эта платформа, построенная на базе стека обновлений Windows, призвана предоставить разработчикам и командам по созданию приложений и инструментов управления специальный API для интеграции обновлений, учитывающий особенности их собственных установщиков», — поясняется в документе Microsoft, опубликованном в прошлом году.

«Оркестратор будет координировать обновления для всех зарегистрированных в системе продуктов, — добавляют в Microsoft. — Он будет поддерживать как форматы MSIX/APPX, так и приложения с собственной реализацией механизма обновлений, например, Win32-программы».

Таким образом, система единых обновлений в Windows 11 будет охватывать практически любые приложения, включая форматы MSIX, APPX и Win32. Разумеется, это станет возможным только в том случае, если разработчик сам зарегистрируется в системе и выполнит все необходимые процедуры.

Microsoft планирует использовать ту же технологию интеллектуального планирования, которая уже применяется для системных обновлений. В частности, при определении времени установки обновлений для сторонних приложений Windows будет учитывать активность пользователя, уровень заряда аккумулятора, состояние сети и общее состояние системы. Цель состоит в том, чтобы обновления не мешали в процессе работы за компьютером. По умолчанию проверка выполняется каждые 22 часа, однако разработчики могут задать иной интервал.

На данный момент система унифицированных обновлений приложений в Windows 11 находится на финальной стадии тестирования.

Весной Microsoft [внедрила](https://habr.com/ru/articles/1028018/) улучшения в Windows Update, чтобы предоставить пользователям больше контроля над процессом установки обновлений, одновременно уменьшая сбои, вызванные частыми или несвоевременными перезагрузками.
