# Выпуск обновления Mesa 26.3

9 ноября 2026 года [состоялся релиз](https://gitlab.freedesktop.org/mesa/mesa/-/tags/mesa-26.3.0) свободной реализации API OpenGL и Vulkan — [Mesa 26.3.0](https://www.mesa3d.org/). Выпуск Mesa 24.0.0 [произошёл](https://habr.com/ru/news/791266/) в феврале 2024 года. Релиз Mesa 25.0 [случился](https://%D0%BC) в феврале 2025 года. Версия Mesa 26.0 [вышла](https://habr.com/ru/news/995766/) в феврале 2026 года.

В ветке Mesa 26.х доступна поддержка графического API [Vulkan 1.4](https://www.opennet.ru/opennews/art.shtml?num=62331) в драйверах ANV для GPU Intel, RADV для GPU AMD, NVK для GPU NVIDIA, HoneyKrisp (hk) для GPU Apple, Turnip для GPU Qualcomm, PanVK для GPU ARM Mali, в программном растеризаторе lavapipe (lvp) и в режиме эмулятора (vn). В драйверах v3dv (GPU Broadcom VideoCore для Raspberry Pi 4+) и dzn (реализация Vulkan поверх Direct3D 12) поддерживается Vulkan 1.0, в драйвере kk (KosmicKrisp, Vulkan поверх Metal) — Vulkan 1.1, а драйвере pvr (GPU Imagination PowerVR) — Vulkan 1.2.

В Mesa 26.х [обеспечивается](https://mesamatrix.net/) полная поддержка OpenGL 4.6 для драйверов Iris (GPU Intel Gen 8+), Radeonsi (AMD), Crocus (старые GPU Intel Gen4-Gen7), zink, llvmpipe, virgl (виртуальный GPU Virgil3D для QEMU/KVM), freedreno (Qualcomm Adreno) и d3d12 (прослойка для организации работы OpenGL поверх DirectX 12) и asahi (GPU AGX, используемый в чипах Apple M1 и M2). Поддержка OpenGL 4.5 доступна для GPU AMD (r600) и NVIDIA (nvc0). Поддержка OpenGL 3.3 присутствует в драйверах softpipe (программный растеризатор) и nv50 (NVIDIA NV50). В драйверах panfrost (GPU ARM Mali) и v3d (GPU Broadcom VideoCore) поддерживается OpenGL 3.1.

Ранее руководитель разработчики проекта Эрик Энгестром [отметил](https://habr.com/ru/news/1032544/) после выпуска Mesa 26.1, что код VirGL для ускорения графики в виртуализированных средах с помощью virglrenderer больше не поддерживается. Если кто-то в ближайшее время не приступит к его поддержке, он может быть удалён. К счастью, в наши дни есть и другие возможности для ускорения графики в виртуальных машинах. Драйверы Intel Iris, Crocus и ANV в этом выпуске также поддерживают поддержку встроенного контекста VirIO-GPU для улучшения паравиртуализации графических процессоров Intel в виртуальных машинах.

Основные дополнения и [исправления](https://9to5linux.com/mesa-26-3-open-source-graphics-stack-officially-released-heres-whats-new) в Mesa 26.3:

- поддержка Vulkan 1.3 в драйвер PanVK для графических процессоров Arm Mali поколений v6 и v7, а также поддержка OpenGL ES 3.0 в драйвере etnaviv для GPU Vivante на аппаратной платформе HALTI5;
- поддержка графических процессоров Mali G68 (в драйвере Panfrost), Mali G715 и G615 (в драйверах Panfrost и PanVK), а также BXM-4-64 (в драйвере PVR);
- поддержка расширения VK\_AMD\_anti\_lag в драйвере RADV;
- улучшения для графических процессоров архитектуры GCN (ранних поколений) в RADV;
- перевод нового компилятора шейдеров Intel Jay в режим работы по умолчанию;
- поддержка 64-битного режима для графических процессоров Intel Nova Lake P;
- включение поддержки графики Intel Nova Lake по умолчанию (она больше не считается экспериментальной);
- поддержка Vulkan Video в драйвере NVK;
- внедрение сжатия буферов для графики Intel (что повышает производительность в играх при использовании DXVK);
- улучшения Vulkan Video для Intel;
- поддержка графических процессоров GFX1171 и ряд других изменений;
- улучшения для множества видеоигр, включая TY the Tasmanian Tiger 3, The Chronicles of Riddick: Assault on Dark Athena, Blockland, The Last of Us Part II Remastered, No Man’s Sky, WUCHANG: Fallen Feathers, Marvel’s Spider-Man Remastered, Wuthering Waves, Witcher 3 Remastered, Witchfire, X-Plane 12, Project Wingman, Space Engineers 2, Counter-Strike 2 и Enshrouded, Forts, Ghost Recon Breakpoint, Half Sword, Insurgency: Sandstorm, OPERATOR, Control Ultimate Edition, Little Inferno, Monster Hunter: World, Warframe, Genshin Impact, Minecraft, Blade Strangers, Wolfenstein II: The New Colossus, Final Fantasy XVI, Persona 3 Reload, Doom 3: BFG Edition, Mario Kart Wii Compiled и Portal 2.
