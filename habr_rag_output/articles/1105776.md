# ИИ научился понимать ДНК и создавать белки по тексту

Исследователи из Китая представили ИИ-модель Pinal, которая по текстовому описанию подбирает структуру и аминокислотную последовательность белка. Почти одновременно Hugging Face вместе с Zhongguancun Academy и Университетом Неаполя выпустила Carbon-X — открытую модель для работы с последовательностями ДНК и обычным текстом.

Pinal работает в два этапа. Сначала модуль T2struct превращает текстовое описание нужной функции в предполагаемую структуру белка. Затем SaProt-T на ее основе составляет аминокислотную последовательность.

Модель содержит около 16 млрд параметров. Для обучения использовалось примерно 1,7 млрд примеров, где последовательности и структуры белков сопоставлялись с описанием их функций. Значительную часть структур взяли из базы AlphaFold.

[*Источник*](https://www.nature.com/articles/s41586-026-11205-z)*.*

Авторы проверили Pinal на четырех задачах. Он создали два фермента и два белка — для метаболического процесса и флуоресцентного. Во всех случаях среди предложенных вариантов удалось найти рабочие молекулы. В одном из экспериментов новый белок увеличил выход продукта в искусственном пути фиксации CO₂ примерно в 1,7 раза по сравнению с природным аналогом из E. coli (Escherichia coli, палочка Эшерихия).

При этом модель пока не выдает готовый результат с первой попытки. Например, для поиска флуоресцентного белка Pinal сгенерировала около 50 тыс последовательностей. После отбора исследователи оставили 29 кандидатов, и только один из них действительно оказался флуоресцентным.

Carbon-X построена на базе Qwen3-14B и содержит 14,8 млрд параметров. Ее можно использовать для анализа участков ДНК — например, оценить последствия замены одного нуклеотида, найти регулирующие участки или определить, насколько вероятно, что конкретная мутация окажется вредной.

Модель также умеет продолжать последовательности ДНК и объяснять результаты обычным языком. Однако разработчики предупреждают, что при генерации длинных участков качество снижается. Кроме того, Carbon-X может ошибаться в координатах и отдельных позициях.

Полную версию Carbon-X можно запускать локально на одной видеокарте с 80 ГБ памяти. Также опубликованы уменьшенные GGUF‑версии. Код и веса распространяются по лицензии Apache 2.0. Модели Pinal и Carbon-X решают разные задачи, но обе упрощают работу с биологическими данными за счет обычного текстового интерфейса. Pinal предназначена прежде всего для проектирования белков, а Carbon-X — для анализа ДНК.
