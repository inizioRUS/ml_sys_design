# В Японии напечатали ноги робота с гибкими «мышцами» и связками из TPU

Исследователи Токийского университета [представили](https://ssk-yoshimura.github.io/muscle-leg/) проект 3D‑печатных мышц для роботов из TPU. Метод испытали на ногах робота.

Все гибкие элементы роботизированных ног изготовили из термопластичного полиуретана TPU 95A на 3D‑принтере Prusa XL, а каркас — из PLA. Свойства мягких деталей регулировали за счёт внутренней конструкции. Например, с помощью увеличения толщины перемычек решётки с 1,5 до 3 мм повысили жёсткость в 28 раз. Благодаря этому также можно печатать мягкую мышцу и более жёсткое сухожилие одной деталью.

В каждой ноге робота предусмотрено шесть крупных искусственных мышц. Часть из них действует сразу на два сустава. Например, можно одновременно разгибать бедро и сгибать колено. Чтобы двигать только одним суставом, система использует другие мышцы, компенсирующие нежелательное движение.

Напечатанные мышцы при сокращении почти не расширяются в сторону. Вместо этого решётка деталей складывается внутрь и не мешает соседним деталям. На печать одной полноразмерной мышцы уходит 20–40 часов. Каналы для тросов тоже закладываются в конструкцию при печати. Метод полностью обходится без литья и сокращает ручную работу.

За движение отвечают моторы в области таза. Они с помощью тросов тянут искусственные мышцы. Связки при этом удерживают суставы и ограничивают свободу движения без подшипников.

В тестах робот выполнял движения с длиной шага 0,4 и 0,8 м. Подвес в эксперименте удерживал конструкцию, принимая часть веса на себя. Образцы выдержали 999 циклов нагрузки без разрыва. При этом жёсткость деталей со временем менялась.

На следующем этапе исследователи планируют применить подход к полноразмерным человекоподобным роботам с полноценным телом и встроенными датчиками.
