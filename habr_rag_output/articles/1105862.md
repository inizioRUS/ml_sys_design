# В Firefox появится функция ускоренного запуска приложений

Microsoft представила в Windows 11 функцию «ускоренного запуска приложений» (Accelerated App Launches) — новый механизм, призванный ускорить открытие программ, процессы которых уже запущены в фоновом режиме. Теперь Mozilla [планирует внедрить](https://bugzilla.mozilla.org/show_bug.cgi?id=2087194) эту технологию в Firefox.

Информация об этом появилась в системе отслеживания ошибок Bugzilla: менеджер по продукту Firefox Дэвид Рубино создал новый запрос, посвященный потенциальной реализации данной функции. По словам Рубино, специалистам Mozilla уже удалось получить доступ к API ускоренного запуска от Microsoft, используя тот же ключ, который Firefox применяет для закрепления ярлыков на панели задач. Первые результаты выглядят многообещающе: в ходе экспресс‑теста локальной сборки Firefox запрос доставлялся к уже запущенному экземпляру браузера примерно за 3 мс — против 70 мс, требовавшихся ранее. Кроме того, при запуске через меню «Пуск» команда теперь передается напрямую в уже работающий браузер. Это не означает, что Firefox станет запускаться в 20 с лишним раз быстрее: приведённые цифры отражают лишь скорость передачи запроса к уже открытому приложению и получены в рамках одного локального теста.

Работа над внедрением продолжается. В экспериментальный патч Mozilla добавлен параметр `widget.windows.accelerated_launch.enabled`, который по умолчанию отключён. Рубино также отметил, что разработчикам предстоит решить, как функция должна вести себя в ситуациях, когда одновременно используется несколько профилей Firefox.

Механизм ускоренного запуска позволяет Windows направлять запросы на открытие приложения непосредственно в тот процесс, который уже работает в системе. В обычном режиме Windows создает дополнительный процесс, который перенаправляет запрос существующему экземпляру программы, а затем завершает свою работу. Новый подход от Microsoft исключает этот промежуточный этап, что должно сделать запуск приложений из меню «Пуск» или с панели задач заметно быстрее. Для сравнения: по данным Microsoft, функция Accelerated App Launches делает запуск браузера Edge примерно на 15% быстрее для большинства пользователей, а при повышенной нагрузке на систему прирост скорости может достигать 33%. Эта функция поддерживается в Windows 11 (версии 25H2, 26H1 и 26H2) при условии установки обновления от октября 2026 года или позднее.

Кроме того, Microsoft предоставляет реализацию технологии «ускоренного запуска приложений» проекту Chromium. Благодаря этому в будущем данную функцию могут внедрить и другие браузеры на базе Chromium — например, Chrome, Brave или Opera.

Между тем [состоялся](https://habr.com/ru/articles/1104514/) релиз стабильной версии Firefox 160.0. В нём появилась функция «Мини‑окно» (Mini Window), позволяющая перенести вкладку или выделенный фрагмент страницы в отдельное окно, которое всегда остаётся поверх других окон; добавлена ​​настройка скорости воспроизведения для режима «Картинка в картинке» (от 0,25 x до 2,0 x) и реализована поддержка воспроизведения файлов формата Matroska (MKV) с аудиодорожками в форматах FLAC, MP3 или PCM, а также внедрены другие функции.
