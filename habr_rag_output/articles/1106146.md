### 1. Кэмп — удобный ИИ для генерации отчетов, аналитических запислк

В [**Кэмпе**](https://eduforms.ru?rid=aabb7c0c8923ed7c&promo=29&component=77&erid=2SDnjePaVBr&ulp=https%3A%2F%2Fkampus.ai%2Fecosystem%2Fskills) для этой работы есть навык «Отчёты, аналитика и бизнес-планы» из раздела «Бизнес». Такой подход удобен, если материалов много, но пока непонятно, какой документ из них нужен. Одни и те же показатели можно оформить как короткую записку для руководителя или подробный отчёт для команды с разбором отклонений.

**Рабочая последовательность:**

1. **Опишите, кому и зачем нужен документ.** Например: руководителю отдела нужно понять, почему выросла стоимость заявки; команде проекта — согласовать изменение сроков.
2. **Передайте цифры и контекст.** Укажите период, единицы измерения, плановые значения, фактические результаты и известные изменения в процессе.
3. **Согласуйте главный вывод.** Попросите отделить то, что следует из данных, от возможных объяснений.
4. **Разверните вывод в документ.** Добавьте расчёты, ограничения, варианты действий и вопросы для решения.

Для начала можно использовать такой запрос:

```
Подготовим аналитическую записку для [получатель]. Нужно решить: [вопрос]. 
Данные за период: [таблица или факты]. Известный контекст: [изменения, события]. 
Требования к документу: [объём, форма, обязательные разделы].
Сначала предложи главный вывод и покажи, какими данными он подтверждается. 
Отдельно перечисли допущения и вопросы. После согласования напиши документ, начиная с вывода, и вынеси расчёты в отдельную таблицу.
```

Внутри навыка полезно различать четыре результата:

- **Отчёт:** что выполнено, какой результат получен, где есть отклонения.
- **Аналитическая записка:** что означает изменение и какой вопрос нужно решить.
- **Стратегия:** цель, варианты действий, ограничения и критерии выбора.
- **Бизнес-план:** описание проекта, исходные условия, расчёты и сценарии на заданных предпосылках.

Для банка, конкурса или внутреннего согласования приложите соответствующие требования. В бизнес-плане заранее задайте исходные предположения: цену, объём продаж, расходы и период расчёта. Нейросеть сможет связать их в документ, а читатель увидит, на чём основан сценарий.

## Как подготовить отчёт с помощью ИИ: от таблицы к выводу

Рассмотрим условный пример маркетингового отчёта. Он нужен, чтобы показать разницу между расчётом показателей и объяснением причин. Все значения ниже учебные.

Есть данные за два сопоставимых периода по 30 дней. В обоих одинаково считаются посещения и заявки.

|  |  |  |  |
| --- | --- | --- | --- |
| **Показатель** | **Период А** | **Период Б** | **Изменение** |
| Посещения | 10 000 | 12 000 | +20% |
| Заявки | 500 | 540 | +8% |
| Расходы на привлечение | 100 000 ₽ | 135 000 ₽ | +35% |
| Конверсия посещений в заявки | 5% | 4,5% | −0,5 процентного пункта |
| Стоимость заявки | 200 ₽ | 250 ₽ | +25% |

Для этого примера предполагается, что посещения и заявки относятся к привлечению, расходы на которое указаны в таблице. Если часть заявок приходит из других источников, сначала нужен корректный разрез по каналам.

### 1. Зафиксируйте формулы

- Конверсия = заявки / посещения × 100%.
- Стоимость заявки = расходы на привлечение / заявки.
- Относительное изменение = (новое значение − старое) / старое × 100%.

Падение конверсии с 5% до 4,5% составляет **0,5 процентного пункта**. В относительном выражении это снижение на **10%**. Эти формулировки обозначают разные способы сравнения.

### 2. Сформулируйте вывод, который следует из чисел

Для начала отчёта подходит такой абзац:

За период Б количество заявок выросло на 8%, расходы на привлечение — на 35%. Стоимость заявки увеличилась с 200 до 250 ₽, а конверсия посещений в заявки снизилась с 5% до 4,5%. Для объяснения изменений нужен разбор по каналам и посадочным страницам.

Здесь есть результат и следующий аналитический вопрос. А утверждение «реклама стала менее качественной» пока не подтверждено: агрегированная таблица не показывает ни состав трафика, ни качество самих заявок.

### 3. Отделите версии от установленных фактов

Снижение общей конверсии может быть связано с изменением долей каналов, аудиторий или страниц. Это возможные объяснения. Чтобы выбрать между ними, нужны дополнительные данные.

Попросите ИИ добавить к каждой версии способ проверки: сравнить конверсию по источникам, долю мобильных посещений, изменения на форме заявки. Такой раздел превращает отчёт в основу следующего действия.

### 4. Соберите документ под адресата

Для руководителя достаточно краткого вывода, таблицы показателей и вопросов для решения. Для специалиста добавьте разрезы, определения метрик и расчёты. Подробности можно вынести в приложение, сохранив ссылку на него в основном тексте.

На основе согласованных расчётов подготовь отчёт для [адресат]. В начале — главный вывод до пяти предложений. Затем таблица показателей, подтверждённые изменения и гипотезы. Для каждой гипотезы укажи, какие данные нужны для проверки. Не делай выводы о выручке, прибыли или качестве заявок, если таких данных нет. Заверши перечнем вопросов для решения, расчёты вынеси в приложение.

## Как создать документ через нейросеть по образцу

Образец помогает сохранить форму: порядок разделов, названия полей, уровень подробности. Перед запуском обозначьте, какие его части нужно использовать. Особенно это важно для прошлых отчётов, где рядом с удачной структурой находятся устаревшие показатели.

Разделите материалы по назначению:

- **Шаблон:** структура, стиль, обязательные элементы.
- **Новые данные:** актуальные суммы, даты, результаты и факты.
- **Требования:** объём, получатель, форма согласования, приложения.

```
Создай новый документ по образцу. Используй из шаблона только структуру, названия разделов и уровень подробности. 
Содержание возьми из актуальных данных. Сначала покажи, какие поля и разделы нужно заполнить, и перечисли недостающие сведения. 
Не переноси из образца имена, даты, суммы и выводы.
Шаблон: [файл]. Новые данные: [файл или текст]. Требования: [описание].
```

При регулярной генерации отчёта сохраняйте описание метрик и правила обработки рядом с шаблоном. Тогда новый период будет сопоставим с предыдущим, а изменения методики можно будет отметить отдельно.

## Word, PDF или таблица: в каком виде передавать результат

|  |  |  |
| --- | --- | --- |
| **Формат** | **Когда выбирать** | **Что проверить** |
| **DOCX / Word** | Нужны правки, согласование, дополнение разделов | Стили заголовков, переносы, таблицы, нумерацию |
| **PDF** | Нужно зафиксировать вид документа для чтения и отправки | Порядок страниц, шрифты, подписи к таблицам и приложения |
| **XLSX / CSV** | Получателю нужны исходные данные и возможность пересчёта | Формулы, типы данных, единицы измерения; CSV не сохраняет оформление книги |
| **TXT / Markdown** | Текст будут переносить в другую систему или оформлять позже | Структуру, заголовки, списки и сохранность ссылок |

Практичный комплект для отчёта — основной документ и отдельная расчётная таблица. В тексте остаются выводы, объяснения и решения, в таблице — данные, по которым можно восстановить расчёт.

## Три вопроса перед выбором нейросети для документов

### Нужен готовый файл или достаточно текста?

Если требуется документ с локальными правками и выгрузкой, начните с агента Study AI. Для работы над выводом и логикой аналитического текста подойдёт навык Кэмпа. При использовании универсальной модели заранее укажите формат результата и доступные инструменты работы с файлами.

### Можно ли сделать отчёт из скана?

Да, сначала нужно получить читаемые данные. PDF Commander поможет распознать страницы; Study AI принимает фотографии конспектов как исходники, а Anara поддерживает OCR в соответствующих планах. После распознавания проверьте числа, десятичные разделители и строки таблиц: от них зависит дальнейший расчёт.

### Как обновлять один отчёт каждый месяц?

Сохраните шаблон, определения показателей, формулы и запрос. Для нового периода передавайте свежую выгрузку и список изменений. Просите обновлять не только таблицы, но и связанные с ними выводы: старое объяснение может не подходить к новым результатам.
