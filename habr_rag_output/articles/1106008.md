# OpenAI и ModRetro выпустили консоль для вайбкодеров

OpenAI объединилась с производителем ретро-устройств ModRetro и [выпустила](https://openai.com/supply/co-lab/chromatic/) специальную версию портативной консоли Chromatic. За $200 пользователь получает устройство в стиле Game Boy Color и картридж, на который можно записывать собственные игры, созданные с помощью Codex. Первую партию уже раскупили.

Для разработки нужно установить в Codex плагин ModRetro Chromatic и описать идею игры: мир, персонажей, механики и правила. Агент собирает проект в GB Studio — редакторе игр для Game Boy Color, — а затем помогает дорабатывать графику, сцены и игровую логику.

Проверить результат можно тремя способами. Первый — запустить игру через браузер в эмуляторе, посмотреть, что получилось, и попросить Codex внести изменения. Можно сразу транслировать игру с компьютера на Chromatic, чтобы проверить управление, изображение и звук. Еще есть возможность собрать ROM-файл и записать его на комплектный Codex Cartridge. После этого играть можно без подключения к компьютеру.

OpenAI уже показала несколько игр, созданных таким способом: головоломку Seedy’s Sweet Garden, dungeon crawler Hollow Descent и ритм-игру Codex Dance.

### Что внутри

Chromatic — отдельное устройство от ModRetro, не новая консоль, разработанная OpenAI с нуля. Codex Edition получила оформление коллаборации и интеграцию с ИИ-агентом.

Характеристики вполне соответствуют ретро-формату:

- 2,56-дюймовый IPS-экран с разрешением 160 × 144 пикселя;
- защитное стекло Gorilla Glass;
- три батарейки AA в комплекте;
- USB-C, динамик и разъём для наушников 3,5 мм;
- совместимость с картриджами Game Boy и Game Boy Color.

Стоимость комплекта — $200. Доставку организовали в США, Канаду, Австралию, Новую Зеландию, Японию, Великобританию и страны ЕС. Следующая поставка ожидается 19 ноября 2026 года.
