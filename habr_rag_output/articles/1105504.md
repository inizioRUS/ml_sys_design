# В Asahi Linux объявили о переходе с использования пермиссивной лицензии MIT на копилефт-лицензию GPLv2+

Разработчики проекта [Asahi Linux](https://asahilinux.org/) (открытый проект по портированию Linux на компьютеры Mac с ARM-чипами Apple Silicon) [объявили](https://asahilinux.org/2026/11/progress-report-7-3/#learning-from-history) о переходе с использования пермиссивной лицензии [MIT](https://ru.wikipedia.org/wiki/%D0%9B%D0%B8%D1%86%D0%B5%D0%BD%D0%B7%D0%B8%D1%8F_MIT) на копилефт-лицензию [GPLv2+](https://ru.wikipedia.org/wiki/GNU_General_Public_License).

Такое решение в команде приняли из-за попыток сторонних разработчиков присвоения трудов Asahi Linux в корыстных целях. Некоторые недобросовестные производители злоупотребляли правами, предоставляемыми лицензией MIT, и заимствовали наработки Asahi для вытеснения оригинального проекта и агрессивной монетизации Linux на системах с чипами Apple Silicon.
